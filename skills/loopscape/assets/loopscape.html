Loopscape renders program loops five ways and exports every one. Flow mode paints each iteration as a glowing particle; Flowchart traces a token across the control-flow graph; Timeline, Array and Spiral each read the same trace. Video export uses your browser's MediaRecorder; GIF export uses an inline GIF89a encoder (no network). Motion honours prefers-reduced-motion. Built self-contained -- save it, open it, ship it.
